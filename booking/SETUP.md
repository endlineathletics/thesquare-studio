# 대관 예약 · 수강신청 — 구글 시트 연결 방법 (약 5분)

연결하면 홈페이지에서 들어온 예약이 구글 시트에 자동으로 쌓이고, 이미 예약된 시간은 홈페이지에서 **예약 불가**로 표시됩니다(중복 예약 방지).
연결하기 전에는 예약 신청 버튼을 누르면 **문자로 예약 신청**하는 방식으로 동작합니다.

## 1. 시트 만들기
1. 구글 드라이브에서 새 **Google 스프레드시트**를 만듭니다. 이름은 예를 들어 `THE SQUARE 대관 예약`.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

## 2. 코드 붙여넣기
1. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣습니다.
2. 새 예약 알림 메일을 받으려면 맨 위 `NOTIFY_EMAIL = ''` 따옴표 안에 이메일을 넣습니다.
3. 저장(💾)합니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙) → **웹 앱**을 고릅니다.
3. 설정:
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 홈페이지에 연결
- 대관 예약: `assets/booking-config.js`의 `api: ''` 따옴표 안에 복사한 URL을 넣습니다.
- 수강신청(관리자 프로그램 준비 전 임시): `assets/apply-config.js`의 `api: ''`에도 **같은 URL**을 넣으면 "수강신청" 시트에 쌓입니다.
- 저장 후 push하면 끝입니다. (Claude에게 URL만 전달해도 됩니다.)

## 운영 방법 — 수강신청
- 신청 1건이 "수강신청" 시트의 한 줄입니다. 상담 후 **상태** 열을 `상담완료`/`등록` 등으로 바꿔 관리하세요.
- 관리자 프로그램이 준비되면 `apply-config.js`의 api를 그쪽 주소로 바꾸면 됩니다(`docs/apply-api.md`).

## 운영 방법 — 대관 예약
- 예약 1시간이 시트의 한 줄입니다. 같은 신청번호가 한 번의 신청이에요.
- 확인 연락 후 **상태** 열을 `확정`으로 바꿔두세요.
- 취소하려면 **상태**를 `취소`로 바꾸면 그 시간이 홈페이지에서 다시 예약 가능해집니다.
- 코드를 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다(URL은 그대로 유지).
