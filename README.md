# THE SQUARE STUDIO

가산 프리미엄 실내 체육관(배드민턴 · 요가 · 코트 대관) 웹사이트. 정적 HTML, GitHub Pages로 호스팅합니다.

- 페이지: `index`(홈: 하늘 사진 + 소개) / `badminton`(대관 → 레슨) / `yoga`(레슨 → 대관) / `contact` / `about` · `rental.html`은 예전 주소용 이동 페이지
- 공통 스타일·스크립트: `assets/style.css`, `assets/main.js`
- 시간표 데이터: `assets/schedule.js` (요가 · 배드민턴)
- 대관 예약: `assets/booking.js` + `assets/booking-config.js` + `assets/booking.css` (배드민턴·요가 페이지 `#rental`, 새 화면 클래스는 `.bk2-*` — 달력·폼·머리는 `style.css` 의 `.bk-*` 그대로)
  - 화면: 01 월 달력(날짜, 담은 시간이 있는 날엔 점) → 02 시간 × 코트 표(세로 = 그 날 시간 칸, 가로 = `COURT 1·2·3`, 요가는 '요가센터' 한 열 · 칸 = '선택' / '—'(예약됨 · 레슨 시간 · 지난 시간)) → 아래 고정 요약 바(`10월 16일(금) · COURT 1·2 · 10:00~18:00 (8시간) · 844,800원` + [예약 확인 →]) → 03 신청 폼(위에 선택 요약). 표는 정해진 높이(PC 520px · 휴대폰 55vh) 상자 안에서만 스크롤되고 머리줄·시간 열이 붙어 있으며, 처음·날짜를 바꿀 때 상자 안을 오늘이면 지금 시각, 아니면 첫 빈 칸 근처로 맞춘다(페이지 스크롤은 그대로).
  - 한 신청 = 날짜 하나 + 이어진 시간 범위 하나 + 코트 1~3개(여러 코트는 같은 시간). 빈 칸을 누르면 시작점, 같은 코트의 다른 칸을 누르면 시작~그 칸(앞뒤 방향, 요가 10분 쉬는 시간도 이어진 칸 · 사이에 '—' 가 있으면 안내 후 누른 칸에서 새로 시작). 범위가 있으면 첫 칸 = 그 코트 빼기(마지막 코트면 전부 해제), 가운데 = 거기까지로 줄이기(모든 코트 같이), 끝 칸 = 그대로, 선택된 코트 열의 범위 밖 = 새로 시작. 선택 안 된 코트 열의 아무 칸 = 그 코트를 같은 시간으로 추가(범위 중 '—' 가 있으면 'COURT 2는 10:00~18:00 중 예약된 시간이 있어요' 안내만). 코트를 모두 고르면 '전체대관'(`wholeLabel`), '3면 동시 가능' 보기는 세 코트가 모두 빈 시간만 '선택' 인 한 열. 다른 날짜 칸을 누르면 담은 시간이 지워지고 그 날에서 새로 시작(날짜만 바꿔 보는 건 그대로). 코트 × 시간이 `maxItems`(72)를 넘으면 바꾸지 않음.
  - 신청은 1코트 1시간 칸(선택 코트 × 범위 칸, court 0부터) 단위로 관리프로그램 `/api/site` 에 보냄. 그 사이 예약이 들어와 `conflict` 면 선택을 지우고 표를 새로 불러옴. `api` 가 비면 문자 접수(새 요약 한 줄). 칸은 버튼(aria-label · aria-pressed, 화살표 키로 이동), 결과 안내는 `#bkLive` 한 곳.
